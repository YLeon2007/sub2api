# Атрибуция русской локализации

[English](RUSSIAN_LOCALIZATION_ATTRIBUTION.md) | Русский

Русская локаль интерфейса и связанная работа по локализации в этом форке были адаптированы из [`imdbcooper/sub2api`](https://github.com/imdbcooper/sub2api), snapshot исходного кода `7a3d490897f6891b3bf18714bedb8cdb8616effe`.

Русский перевод Admin Compliance адаптирован из commit `734ac7e536f27b22c8494c415e4969cac2bf3e68`. История исходного репозитория указывает участника **Slavx** как автора этой локализации.

Импортированные переводы затем были обновлены через официальный Sub2API `v0.1.170`, доведены до явного parity английских и русских ключей, проверены на соответствие placeholders и адаптированы к immutable release identity этого форка. Backend deployment changes исходного форка целиком не импортировались.

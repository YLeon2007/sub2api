# Вывод GPT-5.5 из эксплуатации на аккаунтах Codex с входом через ChatGPT

[English](OPENAI_GPT55_RETIREMENT.md) | Русский

OpenAI вывела GPT-5.5 из Codex с входом через ChatGPT 14 октября 2026 года в 19:00 UTC (15 октября в 03:00 по Азия/Шанхай). Официальный API-доступ не затронут. См. [официальное уведомление о миграции](https://learn.chatgpt.com/docs/models#gpt-55-retirement).

Sub2API применяет это разграничение к upstream-аккаунту, а не к ключу, которым клиенты аутентифицируются в Sub2API:

- Аккаунты OpenAI OAuth и SetupToken, включая теневые копии учётных данных, не могут обслуживать GPT-5.5. Обычное, липкое и компактное планирование исключает эти цели.
- Аккаунты с API-ключом сохраняют поддержку GPT-5.5. В смешанных группах только подходящие upstream'ы с API-ключом могут её обслуживать. Их фактическая доступность моделей остаётся определяющей.
- Публичные списки моделей и каталоги Codex исключают модели, чьи цели выведены из эксплуатации на ChatGPT-аккаунтах группы и не имеют поддерживающего API-ключевого аккаунта. Это также отфильтровывает устаревшие/закреплённые записи каталога до вычисления клиентского ETag.
- Явные административные сопоставления с поддерживаемой заменой остаются действительными. Алиасы, сопоставленные *с* GPT-5.5, исключаются из маршрутизации ChatGPT-аккаунтов. Удалённые каталоги проецируются в публичные алиасы до фильтрации вывода из эксплуатации, с использованием того же единственного шага сопоставления, что и маршрутизация. Метаданные источника и общие кэши upstream сохраняются, включая случаи, когда ID источников также являются ключами алиасов.
- Неподдерживаемые запросы возвращают существующую ошибку `model_not_found` с рекомендациями по миграции, когда диагностика доступности идентифицирует выведенную из эксплуатации подписочную цель. Клиентские chat-запросы не переписываются молча на замену.

## Миграция для администратора

Проверьте сопоставления групп/аккаунтов, клиентские значения по умолчанию, пользовательских агентов и запланированные задачи, выбирающие GPT-5.5. OpenAI рекомендует GPT-6.1 Sol для подходящих платных тарифов или GPT-6 Luna для Free/Go в десктопном приложении, при условии доступности модели. Проверьте доступность на upstream-аккаунте перед выбором замены.

Глобальная настройка `gateway.openai_compact_model` остаётся совместимой с upstream'ами с API-ключом. Если этот fallback разрешается в выведенный GPT-5.5 на ChatGPT-аккаунте, он не применяется; компактные запросы сохраняют выбранную модель. Сопоставление аккаунта только для компактного режима, нацеленное на выведенный GPT-5.5, непригодно для планирования: обновите это явное сопоставление. Никакие сохранённые настройки не переписываются автоматически.

Изменение публичного реестра, удаление тарифов/истории GPT-5.5 или глобальное сопоставление GPT-5.5 с новой моделью не требуется и затронет корректное использование API.

Регрессионные тесты используют локальные фикстуры и заглушки upstream-ответов. Они не устанавливают реальный подписочный доступ к заменяющей модели.

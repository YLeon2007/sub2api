# add-openai-compatible-prompt-audit

[中文](README.md) | Русский

Это изменение добавляет отдельный OpenAI-совместимый модуль аудита безопасности запросов на основе Qwen3Guard, не меняя существующее поведение проверки содержимого. Поддерживаются асинхронный аудит, синхронная блокировка, постоянная очередь задач, рабочая панель событий и отдельная страница администрирования.
